# 🔐 Advanced Caesar Cipher - Python

A professional Python-based encryption and decryption system that implements the Caesar Cipher algorithm. This project allows users to encrypt and decrypt text, numbers, uppercase letters, and lowercase letters using a user-defined shift value.

The project was developed to demonstrate the fundamental concepts of classical cryptography, text manipulation, character encoding, and Python programming.

---

## 📌 Project Overview

The Caesar Cipher is one of the oldest and most widely known encryption techniques. It works by shifting each character in a message by a fixed number of positions in the alphabet.

This project extends the traditional Caesar Cipher by supporting:

- Uppercase letters (A-Z)
- Lowercase letters (a-z)
- Numerical values (0-9)
- Special characters and punctuation

## ⚙️ How the Algorithm Works

### Encryption Process

1. Enter the original text.
2. Enter the shift value.
3. The algorithm checks each character.
4. Alphabetic characters are shifted forward.
5. Numerical values are shifted using modulo arithmetic.
6. Special characters remain unchanged.
7. The encrypted text is generated.

### Decryption Process

1. The encrypted text is processed.
2. The algorithm shifts each character backward.
3. The original message is restored.
